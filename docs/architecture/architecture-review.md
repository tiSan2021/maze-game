## 二、CONCERNS（非阻塞，需主理人知悉/裁决）

### CONCERN-1 · 可访问性分级内容未定稿 → **已解答（L4，经主理人中转 art-director 规格）**
- **现象（原）**：art-director 可访问性规格未定稿，可能反向微调常量表结构。
- **解答（art-director 规格已出，主理人中转）**：
  1. 升级路径绝大多数 = 换常量：三型色盲色表/高对比/迷雾减淡→`palette.ts`；图案密度→`pattern.ts`；动效→`motion.ts`；字号→`metrics.ts`。
  2. 采纳本架构设想：以 **`themes: Record<TierName, Constants>` 对象导出 + 运行时 select** 落地（而非扁平静态 import），绘制/逻辑代码不改。
  3. **唯一需要代码分支的是「关闭迷雾」**：覆盖 `cellRenderState` 返回值、复用关 1–8 全烘焙路径、成本 0.1 人天、**不改变 `visible`/`visited` 集合**（符合 GDD① §4.7）；架构已在 `render/draw-cell.ts` 预留 `AccessibilityMode` 挂载点（main-architecture.md §7）。
  4. 分级口径：art-director 论证 **Basic 级不成立**（图案填充是第二编码通道，关掉则色觉障碍玩家无法区分钥匙与出口，L* 差仅 0.4）→ 实际 **Standard / Comprehensive 二选一**，推荐 Standard（~2.2–2.3 人天）。
- **结论**：非阻塞项已闭合，本架构 §7 已按此形态描述，零返工。

### CONCERN-2 · 视野半径 R=3 → **已裁决（中风险解除）**
- **结论**：art-bible v2 已自解 Q1/Q4——原「R=4~5 渐进」方案**作废**，改为「关卡复杂度渐进 + 视野半径上限 R≤3」。R 上限 3 不可改大，不存在被推翻的可能；2026-09-09 当前值已由 3 缩至 2（缩小不在禁止范围，难度提升），性能预算无需重估。
- **落位**：ADR-03 决策 3（R 上限 3，当前 R=2）、main-architecture.md §9 A5（已裁决）、控制清单 F 组（VISION_R===2 单元断言 + 无 R=4/5 分支）。
- **原中风险（架构级返工）已解除**。

### CONCERN-3 · 性能 8ms 预算是纸面拟合、未经实测（本阶段唯一 `[SPIKE]` 项）

- **现象**：art-bible §3 的成本模型 `3.83ms 固定 + 0.058ms × 视野格数` 由 R=3/R=5 两点拟合得出，且 art-bible 自己在风险 1 里标注"此估算为纸上推算，未经实测"。Phase 1 §5 已把它定为**硬门槛**（<8ms），但架构阶段无法证伪。
- **风险**：中（若实测超标，可能需要动"关 9+ 是否降帧 / 迷宫是否缩小"这类产品级决策，不是纯工程能吸收的）。
- **已做的**：① 三必做前置在清单 F 组声明为**不可省略项**；② 补了四条 CI 代理断言（脏格数 ≤40、`VISION_R===2`、tile 图集早于首帧、`draw-cell.ts` 无路径 API）—— 它们能拦截"有人把增量写成全量""有人绕过 tile 预渲染"这类回归，但**不能替代真机实测**；③ 四级降级预案已写入架构 §4。
- **要求**：Phase 4 的 **E2 渲染 Epic 必须以性能尖峰开场**，跑"三前置全开"与"缺一对照"两组数据。这是 E2 的准入条件，不是收尾动作。

### CONCERN-4 · art-bible 的"四态"与 GDD① 的"四态"不是同一组状态（M-1）→ **已裁决：不实现 C 态，本项闭合**

- **现象**：art-bible §2⑦ 定义 A 当前视野 / B 已探索·已走过 / **C 已探索·未走过** / D 未知；GDD① §4.7 产出 `VIEW_WALKED` / `VIEW_UNWALKED` / `MEMORY_WALKED` / `UNKNOWN`。**C 态在 GDD① 的模型中不可达** —— `visited` 只记录"走过的格"（D11），"看见但没走过"的格一旦移出视野半径就落入 `UNKNOWN`，不存在记忆态。要实现 C 态需引入第三个集合 `seen`。
- **风险**：中。若裁决"要实现 C 态" → 需回改 GDD①（新增 `seen` 集合与第五态）并由 art-bible 给出可达 3:1 的 C/D 区分手段（当前仅靠网格线浓淡 1.52:1 vs 1.21:1，远低于验收线）。这是本轮评审中**唯一可能触发 Phase 2 回改**的项。
- **工程侧建议（默认）**：**维持 GDD① 四态**，art-bible §2⑦ 的 C 行加注"不可达"。理由：① 引入 `seen` 等于"看过即记住"，与 D11「记住的是走过的路」的设计意图相反，且削弱迷雾的探索压力；② C/D 的视觉区分度不满足 3:1，收益不抵复杂度。
- **注意**：这不是"美术做无用功" —— art-bible 的 B 态（铅笔笔迹）与 D 态（空白纸面）都在，且是四态里信息价值最高的两极；只是 C 这一格不产出。
- **裁决（2026-09-07）**：**不实现 C 态**，维持 GDD① 四态。art-director 独立得出同一结论，已把"看见即记住"列为 **AX-1 候选增强、不纳入 MVP**，并由其在 `art-bible.md` §2⑦ 加注「不可达」以消除后续误实现风险。**Phase 2 回改风险消除，本项闭合。**
